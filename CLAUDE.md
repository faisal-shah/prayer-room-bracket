# CLAUDE.md

Ceiling-mount mid-span hook for a 1 in curtain rod (see README.md for the
design basis, dimensions, printing and installation).

## Layout

- `scripts/ceiling_rod_hook.py` — the only source of geometry. Parameter block
  at the top (site measurements in mm converted from inches, then design
  choices), derived values, then build: plate → hook → fuse → stem fillet →
  countersunk holes. `result` is the bracket in design coordinates (ceiling at
  z = 0, +Y toward the room, X along the rod); `print_part` is rotated onto
  its ceiling face for slicing.
- `output/` — STEP (design coordinates), STL and 3MF (print orientation),
  regenerated by `uv run scripts/ceiling_rod_hook.py` from the repo root.
- `docs/img/` — renders used by the README, made with the MCP `render_view`.
- `.claude/skills/b123d-*` — build123d workflow skills installed from the MCP
  server; follow `b123d-modeling` for geometry work.

## Working on the geometry

- Use the build123d MCP server: `execute_file(path="scripts/ceiling_rod_hook.py", result_name="result")`,
  then `measure`, `validate`, `render_view`, `export`. `execute_file` runs in a
  clean namespace and replaces the session history, so re-`show()` anything
  you want to render afterwards.
- The script must import only from the MCP sandbox allow-list (`math`,
  `build123d`, ...). No `os`, `sys`, `pathlib`: the sandbox rejects the import
  statically even inside `if __name__ == "__main__":`. Exports use relative
  paths for that reason.
- `__name__` is `"builtins"` under `execute_file`, so the export block only
  runs standalone.
- The MCP server runs build123d 0.11.1; `uv run` resolves 0.12. `add()` is
  deprecated in 0.12 and `insert()` does not exist in 0.11, so the holes are
  built as a cutter solid (`CounterSinkHole(..., mode=Mode.ADD)` in an empty
  `BuildPart`) and subtracted.
- Fillets: select edges from the same object you call `.fillet()` on
  (algebra mode). Selecting edges from `hook` and filleting inside a
  `BuildPart` that `add()`ed it fails because the builder holds a copy. A
  fillet cannot terminate where its edge chain meets a tangent edge, so the
  plate's underside perimeter is rounded as a closed loop before the fuse and
  the hook's edges are rounded on the standalone hook.
- After each regeneration check: cradle inner cylinder radius 13.135 with its
  lowest point at z = −47.8, two Ø6.2 holes at (±27, 0) with Ø12 × 2.5 mm
  counterbores opening on the underside (z = −8), `clearance` against the
  reference `rod` reporting `touching`.

## Decisions that are not in the code

- The 2 mm `cradle_bias` is deliberate: a hook that hangs low does not take
  weight; a slightly short one can be shimmed with washers. Keep it short.
- Screws sit on the rod's centreline either side of the hook so the load is
  between them and nothing pries; both are 87.5 mm from the wall because
  there is no room for tools between the rod and the wall.
- Stem on the wall side: hidden behind the rod, and the rod enters from the
  room side where there is space to swing it in. Tool access does not depend
  on it since the screws are above the rod.
- PLA: 8 mm walls and a 24 mm wide hook keep stresses around 3 MPa. The plate
  is symmetric about the rod centreline so the hook sits centred on it, and
  the screw holes keep 9 mm of plate from the counterbore to the nearest
  edge. Holes are counterbores for the pan-head #10-12 screws that come with
  the user's Everbilt ribbed anchors; a flat-seated pan head has no wedge
  action, which is the main way countersunk holes crack in printed parts.
